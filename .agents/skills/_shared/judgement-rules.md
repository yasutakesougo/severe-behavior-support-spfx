# 共通判定基準

## 目的

この文書は、すべての Skill が共通で使う判定語、重大度、承認待ち、HOLD の意味を固定します。

## 判定語

### PASS

対象 Gate または監査の通過条件を満たしている状態です。

### READY

次の工程へ進める状態です。

`READY` は準備完了を意味し、Gate 通過の意味で使う場合は `PASS` を優先します。

### HOLD

情報不足、承認待ち、未決定事項、証跡不足により停止する状態です。

`HOLD` は `PASS` でも `READY` でもありません。

### FAIL

重大な不整合またはブロッカーがあり、進行不可の状態です。

### NOT APPLICABLE

その Skill の適用対象が存在しない状態です。

## 重大度

### P0

権限逸脱、データ破壊、誤公開、誤保存、監査不能など、即時停止が必要な問題です。

### P1

マージ前または着手前に解消すべき問題です。

### P2

記録のうえで後続 Issue に送れる改善項目です。

## 共通判定ルール

- `P0` が 1 件でも残る場合は `FAIL`
- 証跡が不足している場合は `PASS` にしない
- 承認待ちは `HOLD`
- 未確認事項は推測で補完しない
- `HOLD` を `READY` と同義に扱わない
- 既知失敗と新規失敗を区別する

## 承認待ちの定義

次のいずれかは承認待ちとみなします。

- merge 承認が未取得
- deploy 承認が未取得
- 本番変更承認が未取得
- SharePoint / Microsoft 365 / Entra ID 変更承認が未取得
- DEC の決定者または承認者が未記録

承認待ち状態では `HOLD` とします。
