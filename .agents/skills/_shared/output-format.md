# 共通出力形式

## 目的

この文書は、Skill の出力を GitHub Issue、PR、設計文書、Findings、handoff に転記しやすい形式へ統一します。

## 出力原則

- 見出しは固定語を使う
- 入力に存在しない情報を推測で埋めない
- 根拠不明の事項は `未確認` と明示する
- 結論、根拠、HOLD、次アクションを分離する
- 判定語は `PASS` / `READY` / `HOLD` / `FAIL` / `NOT APPLICABLE` だけを使う
- 重大度は `P0` / `P1` / `P2` だけを使う

## 共通テンプレート

```md
# <Skill名>

## Summary
- 判定:
- 対象:
- 根拠:

## Findings
| ID | 重大度 | 状態 | 内容 | 根拠 | 対応 |
|---|---|---|---|---|---|
| F-001 | P1 | OPEN |  |  |  |

## HOLD
- なし / または項目列挙

## Approvals
- 必要な承認:
- 承認状態:

## Next Actions
1.
2.
```

## 最低限含める項目

すべての Skill 出力は、最低限次を含めます。

- 判定
- 対象
- 根拠
- HOLD 項目
- 必要な承認
- 次の推奨アクション

## 禁止

- merge、deploy、本番変更を実行済みとして書くこと
- 未確認の承認を承認済みと書くこと
- `HOLD` を解消済みとして扱うこと
