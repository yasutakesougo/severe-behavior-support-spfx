# Roadmap Phase Boundaries

この文書はCompletion RoadmapのPhase間の境界を明示します。

## Phase 1からPhase 2へ

RESPONSIBLE-PERSON-DEMO-V1の責任者レビューが完了し、主要UIの大きな手戻り要因が整理されてからLIVE-SHAREPOINT-V1へ進みます。

Phase 1完了だけではSharePoint / Entra mutationを認可しません。

## Phase 2からPhase 3へ

LIVE-SHAREPOINT-V1のAcceptance Criteriaを満たし、テスト用実環境で主要業務フローと権限境界を確認してからTWO-SITE-PILOT-V1へ進みます。

Phase 2完了だけではProduction GOを認可しません。

## Phase 3からPhase 4へ

Isogo / Honmokuの2事業所で主要業務フロー、事業所分離、現場端末・ブラウザ・ネットワーク条件を確認してからPRODUCTION-READY-V1へ進みます。

Phase 3完了だけではProduction deployを認可しません。

## Phase 4完了

Human Production GO、production deployment、production smokeまで完了した状態を100%とします。

未解決P0 / P1、安全・権限・事業所分離上のblockerがある場合は100%と扱いません。
