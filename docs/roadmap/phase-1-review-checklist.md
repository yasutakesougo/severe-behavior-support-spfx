# Phase 1 Responsibility Review Checklist

Tracking: #299

責任者レビュー時に確認する項目です。

- [ ] 概要画面で判断に必要な情報が見える。
- [ ] 利用者一覧から対象利用者を探せる。
- [ ] 利用者詳細から支援計画へ到達できる。
- [ ] 日々の記録を確認できる。
- [ ] 見直し状況を確認できる。
- [ ] 期限接近や確認待ちが見落としにくい。
- [ ] 現場で使う用語と画面用語が一致している。
- [ ] 操作順序に大きな違和感がない。
- [ ] 責任者として不足する情報を列挙できる。
- [ ] 不要または誤解を招く情報を列挙できる。
- [ ] live SharePoint / Entra未接続を完成機能と誤認しない。
- [ ] 実データを使用していない。

チェック完了はImplementation Start、SharePoint / Entra mutation、Production GOを自動認可しません。
