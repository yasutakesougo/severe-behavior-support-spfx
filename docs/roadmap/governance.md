# Roadmap Governance Boundary

Completion Roadmapは、進捗共有と工程管理のための補助正本です。

既存のDecision SoTを置き換えません。

## このロードマップから派生しない権限

次の権限はこのロードマップから派生しません。

- Implementation Start
- SharePoint mutation
- Entra / Microsoft Graph mutation
- M365 mutation
- Ready
- Merge
- Deploy
- Production GO
- Issue Close

各操作は既存の個別gateとHuman Decisionに従います。

ロードマップ上のPhase移行は、未認可の実装や外部mutationを自動開始する条件ではありません。

## 進捗率の扱い

70〜75%、85%、90%、95%、100%という数値は、責任者・現場・開発で現在地を共有するための目安です。

この数値はAcceptance、Independent Review、Implementation Start、Mutation GO、Production GOの根拠にはしません。

## Phase完了の扱い

各PhaseのIssueに記載したAcceptance Criteriaを満たしたことを確認してから、Phase完了を判断します。

Phase完了だけを理由に、次Phaseの実装や外部mutationを開始しません。
