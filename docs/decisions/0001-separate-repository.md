# ADR 0001: 現行システムと新アプリのリポジトリを分離する

- 状態: 承認
- 決定日: 2026-08-04

## 判断する対象

現行システムは、運用中のキオスクと複数の既存機能を含みます。

新アプリは、同一法人・同一Microsoft 365テナント内の複数事業所で利用することを想定します。

両者は、依存関係、リリース周期、権限、保存契約、障害対応の責任範囲が異なります。

## 決定

新アプリは、Privateの独立リポジトリで新しいGit履歴から構築します。

現行リポジトリのfork、複製、履歴コピーは行いません。

現行システムからは、承認済みの業務上の意味と境界条件だけを参照します。

再利用候補は、新リポジトリで合成fixtureとテストから再構成します。

## 持ち込まないもの

次の資源は、新アプリへ持ち込みません。

- 現行React画面
- 現行の保存RepositoryとSharePoint adapter
- 現行のProvisioningと公開workflow
- localStorageを正本とする実装
- demoデータとfallbackデータ
- 利用者識別子、別名、事業所固有値
- 実在情報または匿名化状態を確認できない情報
- 現行リポジトリのGit履歴

## 結果

現行キオスクの保守と新アプリの開発を分離できます。

新アプリだけを他事業所へ展開できる構成を選べます。

一方、現行コードのファイル単位のコピーは認めません。

共通ライブラリは、複数アプリで安定した再利用が確認されるまで作成しません。
