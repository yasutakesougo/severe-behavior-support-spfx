## 判断する対象

本 DEC が決める対象は次のみとする。

- DEC-AI-ORG-1 で採用した AI開発組織構成（Role / Governance / Skills / Agents / Commands / Workflows / MCP の論理分離）を
  - 本リポジトリ専用とするか
  - 法人内の他アプリでも再利用する共通基盤として扱うか

## 本 DEC で決めないこと

| 対象外 | 判断文書 / 扱い |
|---|---|
| ファイルとディレクトリの物理配置 | ADR-AI-ORG-1 |
| AI 許可操作と人の承認境界（MCP 権限マトリクス） | DEC-AI-ORG-3 |
| 共通ライブラリや共通リポジトリの新設 | 本 DEC では承認しない |
| Adapter 実装（Codex / Cursor / Claude Code 等） | 後続 |
| ディレクトリ新設・既存正本移動・実装着手 | 禁止継続 |
| HOLD の解除 | しない |

## 背景

- DEC-AI-ORG-1 により、論理分離構成の採用は確定した
- 計画正本および当初提案は、同一法人向けの他アプリへも再利用できる開発基盤を想定している
- 一方で ADR 0001 は、複数アプリで安定した再利用が確認されるまで共通ライブラリを作らない方針である
- したがって「再利用する」ことと「今すぐ共通リポジトリや共通パッケージを切り出す」ことは分離して扱う必要がある

## 選択肢

### A. 本リポジトリ専用とする

論理分離構成は `severe-behavior-support-spfx` 専用とする。

他アプリへの横展開は、別途そのリポジトリで再判断する。

### B. 法人内再利用を前提とする共通基盤として扱う（正本は本リポジトリで先行）

論理モデル・判断単位・権限境界の原則は、法人内の他アプリでも再利用できる共通基盤として設計・文書化する。

ただし、現時点の正本置き場は本リポジトリとする。共通リポジトリへの切り出し、共通パッケージ化、他アプリへの強制適用は本 DEC では行わない。

### C. 最初から独立した共通リポジトリへ切り出す

AI開発組織構成の正本を、本アプリとは別の共通リポジトリに置く。

本 DEC 時点ではディレクトリ新設・リポジトリ新設が禁止されているため、選択肢 C は採用できない。

## 決定（提案）

**選択肢 B を採用する。**

AI開発組織構成は、法人内の他アプリでも再利用する共通基盤として扱う。正本は当面本リポジトリで先行する。

理由:

- DEC-AI-ORG-1 の論理分離は、特定アプリ実装に依存しない
- 計画正本の再利用意図と整合する
- ADR 0001 の「安易な共通ライブラリ先行」を避けつつ、文書・原則としての再利用は可能にする
- 選択肢 C は現状の禁止事項（リポジトリ/ディレクトリ新設）と衝突する

## 本決定の効力と非効力（承認後）

### 効力

- 以降の ADR-AI-ORG-1 / DEC-AI-ORG-3 および process 文書は、「法人内再利用を前提とした共通基盤」として矛盾しない表現にする
- 本リポジトリの正本を、他アプリが参照・移植する起点としてよい（強制適用はしない）

### 非効力

- HOLD は維持する
- 実装開始承認にはならない
- ディレクトリ新設は引き続き禁止する
- 既存正本移動は引き続き禁止する
- 共通リポジトリ新設・共通パッケージ切り出しは承認しない
- 他アプリへの即時適用・強制は承認しない
- ADR-AI-ORG-1 / DEC-AI-ORG-3 の内容を先取り・承認しない

## 承認条件

次を満たしたとき、状態を `承認` に更新し、決定日を記録する。

- 人による明示承認がある
- 本 DEC の対象が「再利用範囲のみ」であることが確認されている
- 物理配置・権限境界・共通リポジトリ新設が混在していない
