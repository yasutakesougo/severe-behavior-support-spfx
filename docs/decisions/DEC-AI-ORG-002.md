## 判断する対象

本 DEC が決める対象は次のみとする。

- DEC-AI-ORG-1 で採用した AI開発組織構成（Role / Governance / Skills / Agents / Commands / Workflows / MCP の論理分離）を
  - 本リポジトリ専用の論理モデルとするか
  - 法人内の他アプリでも再利用する論理モデルとするか

## 本 DEC で決めないこと

| 対象外 | 判断文書 / 扱い |
|---|---|
| 正本の物理配置（どのパス・どのリポジトリに置くか） | ADR-AI-ORG-1 |
| 共通リポジトリへの分離 | ADR-AI-ORG-1（本 DEC では承認しない） |
| AI 許可操作と人の承認境界（MCP 権限マトリクス） | DEC-AI-ORG-3 |
| 共通ライブラリや共通パッケージの新設 | 本 DEC では承認しない |
| 他アプリへの適用・複製・移植・共通化 | 各アプリの個別判断と実装開始承認が必要。本 DEC では承認しない |
| Adapter 実装（Codex / Cursor / Claude Code 等） | 後続 |
| ディレクトリ新設・既存正本移動・実装着手 | 禁止継続 |
| HOLD の解除 | しない |

## 背景

- DEC-AI-ORG-1 により、論理分離構成の採用は確定した
- 計画正本（`docs/process/ai-org-onboarding-implementation-plan.md` / PR #45）は、同一法人向けの他アプリへも再利用できる開発基盤を想定している
- 参照 ADR: `docs/decisions/0001-separate-repository.md`
- 参照箇所: 「共通ライブラリは、複数アプリで安定した再利用が確認されるまで作成しません。」
- したがって「再利用可能な論理モデルとして設計する」ことと「今すぐ共通リポジトリ・共通パッケージを切り出す」「他アプリへ適用・移植する」ことは分離して扱う必要がある
- 正本をどこに置くかは ADR-AI-ORG-1 の対象であり、本 DEC に含めない

## 選択肢

### A. 本リポジトリ専用の論理モデルとする

論理分離構成は `severe-behavior-support-spfx` 専用の論理モデルとする。

他アプリへの横展開は、別途そのリポジトリで再判断する。

### B. 法人内の他アプリでも再利用する論理モデルとする

論理分離構成は、法人内の他アプリでも再利用可能な論理モデルとして設計する。

正本の物理配置、共通リポジトリ新設、共通パッケージ化、他アプリへの適用・複製・移植は、本選択肢に含まれない。

## 決定

**選択肢 B を承認する。**

DEC-AI-ORG-1 で採用した論理分離構成は、法人内の他アプリでも再利用可能な論理モデルとして設計する。

本決定は、正本の物理配置、共通リポジトリ新設、共通パッケージ化、他アプリへの適用・複製・移植を承認しない。

正本の配置は ADR-AI-ORG-1 で個別に決定する。

理由:

- DEC-AI-ORG-1 の論理分離は、特定アプリ実装に依存しない
- 計画正本（PR #45）の再利用意図と整合する
- `docs/decisions/0001-separate-repository.md` の共通ライブラリ抽出条件と衝突せず、論理モデルの再利用方針だけを先に固定できる

## 本決定の効力と非効力

### 効力

- 以降の文書は、法人内の他アプリでも再利用可能な論理モデルとして設計する
- 計画正本の「再利用範囲」判断単位を閉じる
- ADR-AI-ORG-1 を、本決定の再利用方針を前提として個別作成してよい

### 非効力

- HOLD は維持する
- 実装開始承認にはならない
- ディレクトリ新設は引き続き禁止する
- 既存正本移動は引き続き禁止する
- 正本の物理配置を決定しない（ADR-AI-ORG-1 まで暫定維持。暫定維持は配置決定ではない）
- 共通リポジトリ新設・共通パッケージ化は承認しない
- 他アプリへの適用、複製、移植、共通化は、各アプリの個別判断と実装開始承認を必要とする。本 DEC はこれらを承認しない
- ADR-AI-ORG-1 / DEC-AI-ORG-3 の内容を先取り・承認しない

## 承認条件の充足

- 人による明示承認を 2026-08-06 に取得した
- 対象が「再利用範囲のみ」であることを独立レビューで確認した
- 物理配置・共通リポジトリ分離・他アプリへの適用または移植が決定内容に混在していないことを確認した
- 独立レビュー結果は P0: 0 / P1: 0 / P2: 0、内容判定 PASS
